01

Scope and data controller

This Privacy Policy applies to the MEnglish mobile application for Android, package com.antkurakin.menglish, published by Anton Kurakin (the "Developer"). It covers the production version distributed through Google Play and other Android application stores.

The application is provided as an educational service. Questions about this Policy or the application's data practices can be sent to kurakin.anton@gmail.com.

02

Data we access and process

Data stored locally

The application stores learning progress, answers, favourites, game scores, streaks, selected languages, sound and interface settings, a randomly generated application user identifier, and downloaded learning content on the user's device. This information supports the application's functionality and is not uploaded to the Developer's own server.

Analytics and technical data

In production builds, MEnglish uses Firebase Analytics and AppMetrica. These services may process the following data for analytics and application improvement:

  • a randomly generated pseudonymous application user ID and analytics installation identifiers;
  • application launches, sessions, screens, and interactions;
  • selected interface and learning languages;
  • selected courses, stories, exercises, and activity types;
  • application version, operating system, device model, screen characteristics, and network information;
  • application installation source and referral information;
  • approximate location derived from a masked or truncated IP address;
  • diagnostic, performance, crash, and error information made available by the analytics SDKs.

The Developer does not send names, email addresses, phone numbers, free-form messages, or learning answers to these analytics services.

Microphone and speech recognition

Voice exercises request access to the microphone only after the user starts a speaking activity. Audio is passed to the speech recognition service configured on the Android device so that spoken words can be converted into text and compared with the exercise answer. Depending on the device and its settings, the speech recognition provider may process audio on the device or transmit it for ephemeral processing under that provider's terms.

MEnglish does not save voice recordings, does not include them in analytics events, and does not send them to the Developer's own server. Users can continue using non-voice exercises without granting microphone permission.

Bluetooth audio devices

On supported Android versions, the application declares Bluetooth connection permission so speech and audio features can work with a connected headset or speaker. MEnglish does not scan for nearby devices, create device profiles, or send Bluetooth device information to the Developer's server.

Learning content and network requests

MEnglish downloads lessons, dictionaries, images, and audio materials over HTTPS from project content hosted on GitHub Pages. As with ordinary web requests, the hosting provider may receive an IP address, request time, requested resource, browser or application user-agent information, and related technical logs.

03

How data is used

The data described above is used to:

  • provide lessons, games, speech practice, and offline progress;
  • remember settings and restore the user's learning state;
  • understand which courses, stories, and exercise formats are used;
  • measure application installation sources;
  • measure application stability and performance;
  • diagnose errors and improve content and functionality;
  • protect the service and comply with applicable legal obligations.

04

Third-party service providers

The following providers process data to deliver specific application functions. Their processing is also governed by their own policies:

  • Google Firebase Analytics Application usage measurement, installation identifiers, sessions, interactions, device information, and approximate location. Firebase privacy and security
  • AppMetrica by Yandex Application usage analytics, technical information, diagnostics, and app performance measurement. Yandex Privacy Policy
  • Android speech recognition service Optional conversion of speech into text when a voice exercise is started. The provider depends on the device configuration. Google Privacy Policy
  • GitHub Pages Delivery of learning content and application updates over HTTPS. GitHub Privacy Statement

05

Sharing, sale, and advertising

Data is transferred only to the service providers described above for application functionality, analytics, diagnostics, content delivery, and speech recognition. The Developer may also disclose information when required by applicable law, a valid legal process, or to protect users and the service from fraud or abuse.

The Developer does not sell personal data. MEnglish does not display third-party advertising, and the Developer does not use application data to provide personalized advertising. The Android advertising ID permission is removed from the application manifest.

06

Data security

Network connections controlled by the application use HTTPS or the encrypted transport provided by Firebase Analytics and AppMetrica. Local application data is protected by the security controls of the Android device. No method of storage or transmission is completely secure, but the Developer limits data collection and uses established service providers to reduce risk.

07

Data retention and deletion

Local learning data remains on the device until the user clears the application's storage or uninstalls MEnglish. The application does not create a user account, so there is no server-side MEnglish account to close or delete.

Analytics information is retained according to the configured retention periods and deletion capabilities of Firebase Analytics and AppMetrica, and only for as long as needed for the purposes described in this Policy. To ask a privacy question or request deletion of data that can be associated with an available application identifier, email kurakin.anton@gmail.com. Requests will be handled within a reasonable time and in accordance with applicable law.

08

Children's privacy

MEnglish is an educational application that may be used by children as well as adults. Children should use the application with the involvement of a parent or legal guardian. The application does not require an account and does not ask children to submit a name, email address, phone number, home address, or other direct contact information.

Pseudonymous analytics identifiers, application interactions, technical data, and optional microphone access are handled as described in this Policy. A parent or guardian can revoke microphone access in Android settings, clear local application data, or uninstall the application. If a parent or guardian believes that a child has provided personal information to the Developer, they should contact kurakin.anton@gmail.com so that appropriate action can be taken.

09

Your choices

  • Microphone: deny or revoke the permission in Android settings and use the rest of the application without voice exercises.
  • Local data: clear MEnglish storage in Android settings or uninstall the application.
  • Network access: use Android network controls; some content updates and analytics will be unavailable while offline.
  • Privacy requests: contact the Developer using the email address below.
