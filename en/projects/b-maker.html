About the product

A book as a single project

B-Maker connects the manuscript with information that usually lives across separate documents and services: text versions, characters, plotlines, locations, notes, goals, and publishing materials.

Each book is stored in its own portable SQLite .bmaker file. It can be moved to another computer, handed to an editor, or included in an existing backup workflow.

Core features

From concept to finished book

01

One book, one file

The structure, versions, comments, goals, cover, and illustrations stay inside one portable project.

02

Versions without fear of revision

Keep several revisions of a chapter or scene, choose the current one, lock finished text, and compare versions.

03

Planning connected to the manuscript

Characters, relationships, arcs, plotlines, and locations link directly to specific chapters and scenes.

04

Structure at any depth

Parts, chapters, subchapters, sections, and scenes can be nested, reordered, and moved through the tree.

05

Editing and quality control

Comments, project-wide search and replace, plus checks for typos, repetition, punctuation, typography, and overly long passages.

06

Publishing output

Full-book preview, a structured publishing package, and export with cover and illustrations to DOCX, EPUB, and PDF.

Workflow

Tools for every stage

Planning

  • manuscript board with statuses and filters;
  • characters, relationships, and arc points;
  • plotlines and a story grid;
  • locations, notes, and goals.

Writing and editing

  • visual editor and focus mode;
  • versions, comparison, and text locking;
  • comments attached to passages;
  • checks for Russian and English text.

Analytics and publishing

  • words, characters, author sheets, and reading time;
  • repetition, long sentences, and filler words;
  • publishing package readiness checklist;
  • TXT, Markdown, DOCX, EPUB, and PDF export.

Reliability

The author keeps control of the data

Portable storage

The manuscript and its related materials remain in one SQLite file without depending on an external cloud structure.

Backups

The application supports manual copies, backup history, restoration, and database integrity checks.

Open formats

Import TXT, Markdown, and DOCX, then publish the finished book in common text and publishing formats.

Ready for AI workflows

OpenAI Responses API settings and the API key are stored outside the book file, and the connection can be tested before use.
