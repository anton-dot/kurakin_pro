B-Maker Support

Help with B-Maker desktop/web usage, project files, exports, and the B-Maker integration for ChatGPT.

Before contacting support

For a product problem, include the platform you are using (Windows, macOS, or Web), the B-Maker version if visible, what you expected to happen, and what happened instead. Please do not send an entire unpublished manuscript unless it is genuinely required to reproduce a problem.

ChatGPT plugin or app issues

If the issue is specific to the B-Maker plugin/app, include the action you asked ChatGPT to perform, whether B-Maker was installed or selected, and the exact error message if one appeared. Do not include API keys, passwords, or other credentials.

Project safety

Before troubleshooting a project file, make a copy of the relevant .bmaker file when possible. B-Maker is local-first, so keeping an independent backup is the safest way to protect important work.
