One writing system across several operating systems.

B-Maker combines a native Windows application with a web app for Mac, Linux, Chromebook, tablets, and other modern-browser devices.

B-Maker / Guides & comparisons / One writing system across several operating systems.
What this page is about

Cross-platform here means access to the same project model on several operating systems. It does not mean that automatic conflict-aware sync is already built in.

Windows plus web

Windows has the native desktop application. Other supported environments use the B-Maker web app in a modern browser.

This covers several operating systems without pretending every platform has identical packaging.

The project can move

A B-Maker project can be downloaded as a portable .bmaker file for backups and deliberate movement between machines.

You remain responsible for the transfer method; B-Maker does not currently claim seamless automatic synchronization.

A practical device mix

A common pattern can be a Windows primary workstation and a Mac, Chromebook, Linux machine, or tablet as a secondary device. The browser version keeps the same core project concepts available.

If automatic cloud collaboration is your primary need, a cloud-first editor may fit better.

Frequently asked questions

Which platforms can use B-Maker?

Windows has a native desktop app. Mac, Linux, Chromebook, iPad, Android tablets, and other devices can use the web app.

Does cross-platform mean automatic sync?

No. Built-in automatic conflict-aware sync is not currently claimed; portability is based on the downloadable project file.
