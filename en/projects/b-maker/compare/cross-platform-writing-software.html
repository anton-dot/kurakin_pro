What this page is about

Cross-platform here means the same project model can be used through native macOS and Windows apps and through the web app. It does not imply built-in conflict-aware cloud sync.

Native desktop on the two main desktop platforms

macOS and Windows both have downloadable desktop packages. On either platform, B-Maker can work with local project files instead of requiring a proprietary cloud account.

Linux, Chromebook, iPad, Android tablets, and other browser-capable devices can use the web app.

The project can move

A B-Maker project is a portable .bmaker file. You can keep it on one machine, back it up using your own storage, or deliberately move it between macOS and Windows.

The browser version can also download the project as a portable file. Automatic multi-device merge or real-time collaboration is not currently claimed.

A practical device mix

You can write on a Mac, continue on Windows, or open the web app from a secondary device. The important part is that manuscript structure, versions, planning, comments, and publishing data follow the same project model.

If seamless cloud collaboration is the primary requirement, a cloud-first editor may still be a better fit.

Frequently asked questions

Which platforms have native B-Maker apps?

macOS and Windows.

Which platforms use the web app?

Linux, Chromebook, tablets, and other modern-browser devices can use the web version. macOS and Windows users can use it too when convenient.

Does cross-platform mean automatic sync?

No. The portable file model gives you control over transfer and backup, but built-in conflict-aware synchronization is not currently claimed.
