Use B-Maker for book writing on Mac — in the browser.

B-Maker does not currently have a native macOS application. On Mac, the full writing workflow is available through the web app in a modern browser.

B-Maker / Guides & comparisons / Use B-Maker for book writing on Mac — in the browser.
What this page is about

This is a browser-based Mac workflow, not a native Mac package. You can download the project as a portable .bmaker file.

What works on macOS

The web app provides the manuscript editor, project structure, collections, Idea Map, planning tools, versions, analytics, preview, publishing workspace, and export.

That makes Mac a practical platform for B-Maker even before a native macOS client exists.

Project portability

The browser project can be downloaded as a .bmaker file for archiving, backup, or movement to another machine.

It does not imply automatic background synchronization; you choose how the file is transferred.

When a native Mac app matters

If Finder integration, native file associations, OS-specific shortcuts, or a fully native offline package are requirements, B-Maker's current Mac offering may not fit yet.

If a modern browser workflow is acceptable, the same core writing system is available without a native install.

Frequently asked questions

Does B-Maker have a native Mac app?

Not currently. On macOS, B-Maker runs in a modern browser.

Can I download my B-Maker project on a Mac?

Yes. The browser project can be downloaded as a portable .bmaker file.
