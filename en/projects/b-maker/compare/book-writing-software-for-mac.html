macOSWeb app

Book writing software for Mac without waiting for a native Mac build.

B-Maker currently runs on macOS in a modern browser. You get the same long-form writing, planning, idea-map, versioning, analytics and publishing workflow without installing a separate native Mac application.

Important:

B-Maker does not currently offer a native macOS application. On a Mac, use the web app. The project can be downloaded as a portable .bmaker file when you want an external copy.

Why use a browser-based writing app on Mac?

For many writers, the useful question is not whether the app came from a DMG installer; it is whether the writing workflow is comfortable and the project remains portable. B-Maker gives Mac users access to the manuscript tree, continuous editor, collections, saved searches, versions, planning, Idea Map, analytics and publishing tools through the browser.

Your book is still a portable project

The browser version does not change the B-Maker project model. Your writing can be downloaded as a .bmaker file containing manuscript structure, versions, planning, comments, illustrations and publishing metadata.

Good fit for mixed-device writers

If you use Windows at one desk and a Mac elsewhere, the same product can cover both environments: native Windows desktop when you want direct local-file handling and the browser on macOS. That is also useful for writers who occasionally move between a MacBook, a work computer and a tablet.

Where native Mac would still be better

A native macOS build could eventually offer tighter Finder integration, direct file associations, a more native Save/Open experience and stronger offline behavior. Those are real advantages. B-Maker's current Mac proposition is therefore practical rather than disguised: use the web app now; native Mac can make sense later if demand justifies it.

What you can do today

Write chapters or articles, organize deep structure, use full-manuscript editing, map ideas, track characters and plotlines, compare versions, run editorial checks, preview the book and export EPUB, PDF, DOCX, TXT or Markdown.

On Mac: open the browser and write.

No fake “native Mac” claim. Just the full B-Maker web workflow and a portable project you can download.
