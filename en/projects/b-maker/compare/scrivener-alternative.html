What this page is about

B-Maker is not a feature-for-feature Scrivener replacement. It is an alternative for writers who value progressive complexity, one portable project, and tighter links between ideas, manuscript, revisions, and publishing.

Start with writing, not configuration

Open a project, add a chapter or article, and write. Collections, characters, plotlines, Idea Map, manuscript board, versions, analytics, and publishing preparation can stay out of the way until they are useful.

This is a different trade-off from a mature power tool: fewer concepts up front, but still room for the project to grow.

One portable project

B-Maker uses a portable .bmaker project file. The manuscript, versions, planning data, comments, cover, illustrations, and publishing information can remain together without a mandatory proprietary cloud.

There is no built-in automatic cross-device sync today; portability means you keep control of the file and move or back it up using storage you choose.

When Scrivener is still the better choice

Scrivener is the safer choice if you need its mature Compile system, established native Mac/iOS ecosystem, very deep metadata, or an existing workflow your team already knows.

B-Maker is strongest when you want a clean start and an integrated path from notes and visual planning to text and final output.

Frequently asked questions

Is B-Maker simpler than Scrivener?

The entry path is intentionally simpler. Deeper tools are present, but B-Maker tries not to require them before you can start writing.

Can I move a B-Maker project between computers?

Yes. A project can be downloaded as a portable .bmaker file and moved or backed up using storage you already use.
