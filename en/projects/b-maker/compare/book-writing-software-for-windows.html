WindowsDesktop

Book writing software for Windows that keeps the project local.

B-Maker has a native Windows application for writers who want a desktop workflow, local project files, and deeper book tools without making cloud storage mandatory.

Windows workflow

Download the desktop application, open or create a .bmaker project, and work directly with local files. The same project can include manuscript structure, versions, planning, images, analytics and publishing metadata.

Write first

Create a project, add a chapter, and start typing. B-Maker does not require a planning phase before the first paragraph. When the manuscript grows, you can introduce collections, saved searches, character and plot planning, an Idea Map, editorial checks and publishing tools.

Local files fit normal Windows habits

A project remains a portable file you can copy, rename, archive, back up, place on another drive or move with a cloud service you already trust. The application also provides backups and integrity checks inside the project workflow.

For long-form structure, not just pages

Use an arbitrary-depth manuscript tree, full-manuscript continuous editing, manual collections, saved searches and a manuscript board. Versions live inside sections, so rewrites do not require a directory full of almost-identical Word files.

Plan and publish in the same application

Characters, relationships, arcs, plotlines, locations and visual idea boards stay connected to the text. At the end, preview the complete book and export EPUB, PDF, DOCX, TXT or Markdown.

Need another operating system too?

The native desktop build is currently for Windows. B-Maker also runs in a modern browser on Mac, Linux, Chromebook and tablets, so the product can still be used when your writing moves to another device.
