LinuxChromebook

Long-form writing software for Linux and Chromebook in the browser.

B-Maker does not require a native Linux package to be useful. Open the web app and use the same manuscript, planning, versioning, analytics and publishing workflow from a modern browser.

Current platform model

Windows has a native desktop app. Linux and Chromebook use B-Maker through the browser. Projects can be downloaded as portable .bmaker files when you want an external copy.

Why browser delivery matters on Linux

Desktop Linux is fragmented across distributions and packaging formats. A browser-based workspace avoids waiting for separate packages while still giving access to the core writing system. Chromebook benefits for the same reason: no local installer is required.

Not just a text box

The web app includes long-form manuscript structure, continuous editing, manual collections, saved searches, versions, comments, character and plot planning, the Idea Map, analytics, editorial checks, preview and publishing export.

Portable project instead of browser lock-in

The web version can export the working project as a .bmaker file. That means using the browser does not require treating browser storage as the only copy of the work.

Good fit for mixed environments

A writer can use Linux on a desktop, Chromebook while traveling, and Windows elsewhere without switching to a completely different writing system. The interface stays the same even if file-handling details differ between platforms.

Where a native Linux build could help

Native file associations, tighter desktop integration and a stronger offline experience are reasonable future advantages. Today, the web app is the practical way to cover Linux and Chromebook without delaying the rest of the product.
