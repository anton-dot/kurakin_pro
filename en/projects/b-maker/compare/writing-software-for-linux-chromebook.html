Long-form writing on Linux and Chromebook — without a native package.

B-Maker currently reaches Linux and ChromeOS through the web app. The workflow is browser-based, while the project can still be downloaded as a portable file.

B-Maker / Guides & comparisons / Long-form writing on Linux and Chromebook — without a native package.
What this page is about

Use the same manuscript, planning, versioning, analytics, and publishing model in a modern browser. Native Linux packages are not currently claimed.

Browser-based long-form work

The web app supports books, article collections, manuscript structure, full-manuscript editing, Idea Map, planning entities, versions, analytics, preview, and export.

Linux support does not depend on a separate desktop package.

A portable project remains available

The browser project can be downloaded as .bmaker for backup and movement between machines.

B-Maker does not currently promise automatic multi-device synchronization; portability and sync should not be confused.

Who this fits

Linux and Chromebook users who are comfortable with browser-based tools can use B-Maker without switching operating systems. Writers who require a native Linux package should treat that as a current limitation.

The web approach also makes Chromebook a viable secondary writing or review device.

Frequently asked questions

Is there a native B-Maker Linux app?

Not currently. Linux uses the B-Maker web app.

Does B-Maker work on Chromebook?

Yes through a modern browser, with the same browser-based project workflow.
