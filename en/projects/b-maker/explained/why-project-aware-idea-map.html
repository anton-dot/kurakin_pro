Idea MapOne source of truth

Why should an idea map know about the manuscript?

Because a whiteboard becomes expensive when it starts duplicating a book that continues changing somewhere else.

The principle

A node representing Chapter 5 should be able to point to Chapter 5, not become another copy of its name and metadata.

Copied diagrams drift

Move a chapter, rename a character or change a plotline and a separate diagram becomes stale unless somebody updates it. That creates a second source of truth.

Project-aware nodes keep visual thinking attached to real work

Chapters, scenes, characters, plotlines and planning cards can appear on the map while remaining connected to their actual project entities. The board changes perspective, not ownership.

This is what makes multiple views safe

The manuscript tree, board, Story Grid and Idea Map can disagree about layout because they answer different questions, while still referring to the same underlying object.
