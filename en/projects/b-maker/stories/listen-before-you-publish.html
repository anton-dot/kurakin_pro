The workflow

Write normally. When visual proofreading starts to become too familiar, switch channels and listen to the same text.

1. Read the current section

Start with the chapter you are editing. Use section, selection, cursor or section-with-subsections scope depending on how much context matters. Keep follow-reading enabled so the text remains connected to the sound.

2. Fix what sounds wrong, not what merely sounds different

Awkward rhythm, repeated words, mechanical dialogue and sentences that run out of breath are good candidates. A synthetic voice is not an actor, so do not rewrite every sentence simply because the performance is flat.

3. Choose the voice for the job

System and browser voices are useful for quick listening. Downloaded offline voices are better when you want the same voice across sessions and need to create an audio file locally.

Screenshot: Text-to-speech settingsShow speech engine selector with System voices / Browser voices / Piper / Supertonic 3, downloaded voices, speed and sound profile.assets/img/bmaker/bmaker-story-audio-02.webp

4. Export a listening copy

When the section is stable, create one MP3 or split audio by structure level. Listen away from the desk and mark issues for the next pass. The audio is disposable; the manuscript remains the source of truth.

5. Return to the text

Auditory editing is useful because it returns you to the manuscript with different evidence. The goal is not to produce an audiobook. The goal is to hear a sentence before a reader has to fight it.
