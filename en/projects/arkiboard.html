ArkiBoard

Design software systems with linked diagrams, interaction scenarios, and decision records in one project. No account required.

Open in browser ↗

One model, multiple diagrams

A system overview shows boundaries; a detailed diagram shows services and how they connect. In ArkiBoard, a component can appear on several diagrams. You can position it independently in each view while keeping its properties in sync.

Link requirements, scenarios, and architecture decision records (ADRs) to the same model. During review, you can see both how the system fits together and the trade-offs behind the design.

What you can do in ArkiBoard

01

Model a system

Drill down from system context to containers and components with C4. Use built-in shapes for services, data stores, queues, topics, observability, and security.

02

Reuse architecture fragments

Save groups with their settings, notes, and internal connections in a personal library. Transactional Outbox and Inbox examples are available to get you started.

03

Play through scenarios

Define sequential and parallel steps, conditions, and compensating actions. Play the flow on the diagram or show it as a sequence diagram.

04

Document decisions

Link requirements and their acceptance criteria to components and ADRs. Record alternatives, assumptions, risks, and why you chose an approach.

05

Estimate capacity

Compare a baseline workload with tenfold growth. Estimate traffic, storage, queues, and latency using your own inputs and assumptions.

06

Review the architecture

Find potential single points of failure, cycles, and long chains of synchronous calls. Use the findings to guide a review, not as a substitute for testing.

Import, export, and storage

Diagram import

Bring in diagrams from draw.io, PlantUML/C4, and Mermaid. Preview the detected component types and connections before importing.

Documentation and export

Save diagrams as SVG, PNG, or PDF, export Markdown documentation with Mermaid diagrams, or share a standalone HTML report with scenario playback.

Local projects

Projects autosave in the current browser without server sync. Export an .archd file to back up or move the full editable model.

Start with a diagram

Create a blank project or explore the built-in Outbox and Inbox examples.
