Critical gaps

    Ready-to-share review summary

    This is a lightweight review, not a full audit. The score is most useful as a prompt to test concrete scenarios: a new requirement, load growth, dependency failure, data migration, or component replacement.

    What it evaluates

    Not the stack. The system's ability to change

    The same stack can support both excellent and very expensive architecture. This review focuses on boundaries, failure isolation, data contracts, trust boundaries, operability, and the effort required for typical product changes.

    If a weak area does not affect real business scenarios, there is no reason to improve it for the score. If it does, you now have a concrete architecture decision to discuss.
