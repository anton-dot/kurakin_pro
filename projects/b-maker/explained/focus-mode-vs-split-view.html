Зачем одновременно Focus Mode и Split View?

Потому что иногда контекст — шум, а иногда именно контекст и нужен для работы.

Разница

Focus Mode уменьшает видимый контекст. Split View намеренно сохраняет два контекста рядом.

Focus Mode — для локальной работы

Закончить сцену, переписать тяжёлый абзац, написать черновик с нуля — часто проще, когда интерфейс и соседняя структура временно исчезают.

Split View — для работы со связями

Сравнить главу с заметками, держать reference рядом, смотреть соседний раздел или редактировать с опорой на другой кусок проекта.
