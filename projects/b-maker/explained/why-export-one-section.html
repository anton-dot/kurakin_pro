ExportНесколько результатов

Зачем экспортировать один раздел, а не весь проект?

Потому что один авторский проект может содержать несколько вещей, которые нужно отправлять, публиковать или обсуждать отдельно.

Принцип

Проект — рабочий контейнер. Конкретный deliverable может быть меньше.

В книжном проекте могут жить и статьи

В архиве хранятся опубликованные тексты. Одну часть книги нужно отправить редактору раньше остальных. Для proposal нужны только sample chapters. Экспорт всего проекта здесь просто неправильная единица.

Иерархия уже даёт полезные границы

Если раздел содержит подразделы, экспорт ветки позволяет использовать существующую структуру. Не нужно копировать материал во временный проект только ради одного файла.

Особенно полезно в сценарии «статьи → книга»

Один проект может сохранять старые публикации и при этом выдавать отдельную текущую статью, одну часть книги или полную рукопись.

Export не должен диктовать структуру проекта

Организуйте проект для письма и мышления. Границу экспорта выбирайте тогда, когда понятно, что реально нужно получателю.
