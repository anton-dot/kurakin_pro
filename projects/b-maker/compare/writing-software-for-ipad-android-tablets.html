Используйте B-Maker на планшете как браузерное рабочее пространство.

У B-Maker сейчас нет нативных приложений iPadOS или Android. На планшетах продукт работает через Web App в современном браузере.

О чём этот материал

Планшет удобен для письма, вычитки, чтения сквозной рукописи, планирования и лёгкой работы с проектом. Проект можно скачать как переносимый .bmaker.

Дополнительная поверхность для письма

Браузерный процесс даёт доступ к той же модели: рукопись, коллекции, Idea Map, планирование, версии, аналитика, preview и экспорт.

Touch-интерфейс и ограничения браузера означают, что планшет может быть лучше как дополнительное устройство, а не замена desktop для каждого сценария.

Без притворства native-приложением

Web App не называется нативным tablet app. Если нужны специфические интеграции ОС или отдельный офлайн-пакет, это текущее ограничение.

Если работа в браузере приемлема, проект доступен без установки приложения из store.

Переносимая копия

Web-проект можно скачать как .bmaker для резервирования или переноса. Автоматическая синхронизация между устройствами сейчас не заявляется.

Так tablet-сценарий остаётся предсказуемым и не строится на скрытых предположениях о sync.

Частые вопросы

Есть нативный B-Maker для iPad или Android?

Сейчас нет. Используется Web App.

Можно скачать проект из браузера на планшете?

Да. Проект скачивается как переносимый .bmaker.
