О чём этот материал

Cross-platform здесь означает доступ к одной модели проекта на разных ОС. Это не обещание уже встроенного автоматического conflict-aware sync.

Windows плюс Web

На Windows есть native desktop-приложение. Остальные поддерживаемые среды используют B-Maker Web App в современном браузере.

Так продукт работает на нескольких ОС без заявления, будто упаковка на всех платформах одинаковая.

Проект можно переносить

B-Maker позволяет скачать проект как переносимый .bmaker для резервирования и осознанного переноса между компьютерами.

Способ передачи выбирает пользователь; бесшовная автоматическая синхронизация сейчас не заявляется.

Практическая комбинация устройств

Например, основной Windows-компьютер и Mac, Chromebook, Linux-машина или планшет как дополнительное устройство. Браузерная версия сохраняет основные сущности и рабочие процессы проекта.

Если главным требованием является automatic cloud collaboration, cloud-first редактор может быть логичнее.

Частые вопросы

На каких ОС работает B-Maker?

Windows имеет нативную desktop-версию. Mac, Linux, Chromebook, iPad и Android-планшеты используют Web App.

Cross-platform означает automatic sync?

Нет. Встроенный conflict-aware sync сейчас не заявляется; переносимость основана на файле проекта.
