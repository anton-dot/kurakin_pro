B-Maker: сравнения и гайды

WindowsMacLinuxChromebook

Кроссплатформенная программа для текстов без превращения рукописи в cloud-only объект.

B-Maker сочетает нативное приложение Windows и браузерную версию для Mac, Linux, Chromebook и планшетов. Модель переносимого проекта остаётся общей.

Текущее покрытие

Windows: нативное desktop-приложение. Mac, Linux, Chromebook и планшеты: современный браузер. Web-проект можно скачать как переносимый .bmaker.

Кроссплатформенность не обязана означать одинаковый установщик

Продукт может работать на нескольких ОС без отдельного native-клиента для каждой. B-Maker использует desktop-приложение там, где сегодня важнее всего прямая работа с локальными файлами, а Web App покрывает остальные устройства автора.

Рабочая система остаётся одной

Структура рукописи, версии, сквозной редактор, коллекции, сохранённые поиски, карта идей, персонажи и сюжетные линии, аналитика, предпросмотр и публикация остаются частью одного B-Maker-процесса.

Полезно тем, кто пишет на нескольких устройствах

Черновик можно делать на Windows-десктопе, редактировать на MacBook, проверять структуру с Chromebook или открыть проект с планшета. Главное — не создавать отдельную систему организации под каждое устройство.

Переносимость важнее обещания магического sync

B-Maker сейчас не обещает бесшовную собственную синхронизацию между всеми устройствами. Корректнее другая модель: проект остаётся файлом под вашим контролем, а Web App обеспечивает доступ на дополнительных ОС. Файл можно переносить через тот диск или облачный сервис, которому вы уже доверяете.

Почему не ждать native-клиента для каждой платформы

Отдельные приложения для всех desktop и mobile ОС замедляют развитие самого продукта. Web-покрытие позволяет сначала улучшать работу с текстом, а native-клиенты добавлять позже там, где реальный спрос оправдывает стоимость поддержки.

Одна система письма на тех устройствах, которые у вас уже есть.
