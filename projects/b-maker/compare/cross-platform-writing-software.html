О чём этот материал

Cross-platform здесь означает одну модель проекта в нативных приложениях macOS и Windows и в Web App. Это не обещание уже встроенной conflict-aware синхронизации.

Нативный desktop на двух основных платформах

Для macOS и Windows есть отдельные скачиваемые desktop-пакеты. На обеих платформах B-Maker может работать с локальными файлами проекта без обязательной proprietary cloud-учётной записи.

Linux, Chromebook, iPad, Android-планшеты и другие устройства с современным браузером используют Web App.

Проект можно переносить

Проект B-Maker — переносимый файл .bmaker. Его можно хранить на одном компьютере, резервировать привычным способом или осознанно переносить между macOS и Windows.

Web App тоже позволяет скачать проект как переносимый файл. Автоматический merge между устройствами и real-time collaboration сейчас не заявляются.

Практическая комбинация устройств

Можно писать на Mac, продолжить на Windows или открыть Web App со второго устройства. Важнее всего, что структура рукописи, версии, планирование, комментарии и издательские данные используют одну модель проекта.

Если главным требованием является бесшовная облачная совместная работа, cloud-first редактор может быть логичнее.

Частые вопросы

Для каких платформ есть нативные приложения B-Maker?

Для macOS и Windows.

Какие платформы используют Web App?

Linux, Chromebook, планшеты и другие устройства с современным браузером. Пользователи macOS и Windows тоже могут открыть Web App при необходимости.

Cross-platform означает automatic sync?

Нет. Переносимый файл даёт контроль над хранением и передачей, но встроенная conflict-aware синхронизация сейчас не заявляется.
