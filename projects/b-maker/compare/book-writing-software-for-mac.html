B-Maker для книг на Mac — через браузер.

У B-Maker сейчас нет нативного приложения macOS. На Mac полный рабочий процесс доступен через Web App в современном браузере.

B-Maker / Гайды и сравнения / B-Maker для книг на Mac — через браузер.
О чём этот материал

Это браузерный сценарий на Mac, а не native-пакет. Проект можно скачать как переносимый файл .bmaker.

Что работает на macOS

Web App включает редактор рукописи, структуру проекта, коллекции, Idea Map, планирование, версии, аналитику, preview, publishing workspace и экспорт.

Поэтому Mac уже можно использовать как полноценную рабочую платформу B-Maker, даже без нативного клиента.

Переносимость проекта

Браузерный проект скачивается как .bmaker. Его можно архивировать, резервировать или переносить на другой компьютер.

Это не означает автоматическую фоновую синхронизацию между устройствами — способ передачи файла выбираете вы.

Когда важен native Mac

Если критичны Finder integration, нативные file associations, системные shortcuts или отдельный офлайн-пакет, текущий Mac-сценарий B-Maker может не подойти.

Если современный браузер приемлем, основная система письма доступна без установки нативного приложения.

Частые вопросы

Есть нативная версия B-Maker для Mac?

Сейчас нет. На macOS используется Web App.

Можно скачать проект на Mac?

Да. Браузерный проект скачивается как переносимый .bmaker.
