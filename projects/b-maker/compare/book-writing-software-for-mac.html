О чём этот материал

B-Maker доступен как нативное desktop-приложение для macOS. Desktop-версия работает с локальными файлами проекта; браузерная версия остаётся дополнительным вариантом.

Сначала текст

Создайте проект, добавьте главу или статью и пишите. Не нужно заранее проектировать сложную систему. Коллекции, планирование, Idea Map, версии, аналитика и издательская подготовка могут подключаться по мере роста проекта.

Нативный Mac, а не браузерный обходной путь

Пакет для macOS — это desktop-версия B-Maker с прямой работой с локальными файлами. Проект можно хранить на Mac, резервировать привычным способом и переносить между компьютерами как один файл .bmaker.

Web App по-прежнему доступен, если устанавливать приложение неудобно, но теперь это не единственный сценарий работы на Mac.

Один проект — не только рукопись

В проекте могут жить рукопись, версии, комментарии, персонажи, сюжетные линии, локации, доски Idea Map, карточки планирования, обложка, иллюстрации, аналитика и издательские данные. Это уменьшает необходимость держать рядом вторую систему планирования.

Local-first не означает automatic sync

B-Maker не требует обязательного proprietary cloud для рукописи. Проект остаётся файлом под вашим контролем. Встроенная conflict-aware синхронизация сейчас не заявляется, поэтому способ резервирования и переноса между устройствами выбираете вы.

Частые вопросы

Есть нативная версия B-Maker для Mac?

Да. Нативный пакет для macOS доступен для скачивания.

Можно работать без облака?

Да. Desktop-проект — локальный переносимый файл .bmaker.

Браузерная версия осталась?

Да. Web App доступен вместе с нативными приложениями для macOS и Windows.
