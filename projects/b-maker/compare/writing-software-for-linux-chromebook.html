B-Maker: сравнения и гайды

LinuxChromebook

Программа для длинных текстов на Linux и Chromebook — прямо в браузере.

B-Maker не требует отдельного Linux-пакета, чтобы быть полезным. Откройте Web App и работайте с той же рукописью, планированием, версиями, аналитикой и публикацией из современного браузера.

Текущая модель платформ

На Windows есть нативное desktop-приложение. На Linux и Chromebook B-Maker используется через браузер. Проект при необходимости можно скачать как переносимый файл .bmaker.

Почему браузер особенно уместен на Linux

Desktop Linux разделён между дистрибутивами и форматами пакетов. Web-версия позволяет не ждать отдельные сборки, но всё равно использовать основную систему работы. Для Chromebook причина ещё проще: ничего не нужно устанавливать локально.

Это не просто поле для текста

В Web App доступны структура длинной рукописи, сквозной редактор, ручные коллекции, сохранённые поиски, версии, комментарии, персонажи и сюжетные линии, карта идей, аналитика, редакторские проверки, предпросмотр и экспорт.

Переносимый проект вместо привязки к браузеру

Браузерный проект можно выгрузить как .bmaker. То есть использование Web-версии не означает, что единственная копия работы обязана оставаться внутри browser storage.

Удобно для смешанной среды

Можно писать на Linux-десктопе, брать Chromebook в дорогу и иногда открывать тот же продукт на Windows, не переключаясь между разными системами организации текста.

Где native Linux всё-таки был бы лучше

Ассоциации файлов, более тесная интеграция с desktop и надёжный offline-сценарий — реальные преимущества нативного клиента. Сегодня Web App — практичный способ покрыть Linux и Chromebook, не откладывая развитие основной версии.

Откройте браузер — рабочий процесс останется тем же.
