Длинные тексты на Linux и Chromebook — без native-пакета.

На Linux и ChromeOS B-Maker сейчас работает через Web App. Рабочий процесс браузерный, при этом проект можно скачать как переносимый файл.

B-Maker / Гайды и сравнения / Длинные тексты на Linux и Chromebook — без native-пакета.
О чём этот материал

Рукопись, планирование, версии, аналитика и публикация доступны в современном браузере. Нативный Linux-пакет сейчас не заявляется.

Длинный текст в браузере

Web App поддерживает книги, коллекции статей, структуру рукописи, сквозной редактор, Idea Map, planning-сущности, версии, аналитику, preview и экспорт.

Поддержка Linux не зависит от отдельной desktop-сборки.

Переносимый проект остаётся

Браузерный проект можно скачать как .bmaker для резервирования и переноса между компьютерами.

Автоматический multi-device sync сейчас не обещается: переносимость файла и синхронизация — разные возможности.

Кому подходит

Если браузерные инструменты на Linux или Chromebook вас устраивают, B-Maker позволяет не менять ОС ради writing-программы. Если нужен именно нативный Linux-пакет, это текущее ограничение.

Chromebook также может быть удобным дополнительным устройством для письма и вычитки.

Частые вопросы

Есть нативное приложение B-Maker для Linux?

Нет, сейчас Linux использует Web App.

Работает B-Maker на Chromebook?

Да, через современный браузер.
