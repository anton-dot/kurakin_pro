B-Maker: сравнения и гайды

WindowsDesktop

Программа для написания книг на Windows с локальным проектом.

У B-Maker есть нативное приложение для Windows: обычный desktop-сценарий, локальные файлы проекта и глубокие инструменты для книги без обязательного облака.

Как это работает на Windows

Скачайте desktop-приложение, создайте или откройте файл .bmaker и работайте напрямую с локальным проектом. Внутри одного файла остаются структура рукописи, версии, планирование, изображения, аналитика и материалы для публикации.

Сначала текст

Создайте проект, добавьте главу и начинайте писать. B-Maker не требует сначала заполнить сложную схему книги. По мере роста рукописи можно подключать коллекции, сохранённые поиски, персонажей, сюжетные линии, карту идей, редакторские проверки и издательские инструменты.

Локальные файлы вписываются в привычный Windows-процесс

Проект можно копировать, архивировать, резервировать, переносить на другой диск или синхронизировать через тот облачный сервис, которому вы уже доверяете. В самом B-Maker есть история резервных копий и проверки целостности.

Структура длинного текста, а не просто страницы

Используйте дерево любой глубины, сквозной редактор всей рукописи, ручные коллекции, сохранённые поиски и доску рукописи. Несколько редакций живут внутри раздела, поэтому не приходится поддерживать каталог почти одинаковых Word-файлов.

Планирование и публикация в том же приложении

Персонажи, отношения, арки, сюжетные линии, локации и визуальная карта идей остаются связаны с текстом. В конце можно увидеть всю книгу целиком и экспортировать EPUB, PDF, DOCX, TXT или Markdown.

А если нужен другой компьютер?

Нативная desktop-версия сейчас предназначена для Windows. На Mac, Linux, Chromebook и планшетах B-Maker работает в современном браузере, поэтому проект не привязывается к одной ОС.
